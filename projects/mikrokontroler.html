Mikrokontroler – Pakan Ikan Otomatis

Automatic Fish Feeder using Arduino Microcontroller

Sekolah Vokasi Universitas Gadjah Mada

Period September 2022 – January 2023
Institution Sekolah Vokasi UGM
Category Embedded Systems & IoT
Status Completed

Project Overview

About the Project

This microcontroller practicum project involved designing and building an automatic fish feeder system using an Arduino Uno microcontroller. The system was engineered to dispense fish feed at scheduled intervals without manual intervention, making it ideal for fish farms and aquaculture applications.

The hardware design integrated a servo motor mechanism to control the feed dispenser, an RTC (Real-Time Clock) module to manage precise feeding schedules, and an ultrasonic sensor to monitor feed level status. The Arduino was programmed in C++ to coordinate these components according to a predefined feeding timetable.

The project resulted in a fully functional automatic feeder prototype that successfully automated the feeding process, demonstrating practical application of embedded systems and IoT principles learned throughout the microcontroller practicum course.

Results

Key Outcomes

Integrated a servo motor dispenser mechanism for controlled and precise feed release.
Implemented an RTC module for accurate real-time scheduling independent of the microcontroller's internal clock.
Gained hands-on experience in embedded C++ programming, hardware-software integration, and sensor interfacing.
