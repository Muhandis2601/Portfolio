PLC Programming for Size-Based Conveyor Sorting System with OMRON

Institution Sekolah Vokasi UGM
Category Industrial Automation
Status Completed

Project Overview

About the Project

The Industrial Automation project focused on designing and programming a Programmable Logic Controller (PLC) system to automate a conveyor sorting line. The system was programmed to detect and sort objects on the conveyor belt based on their physical size — a common requirement in modern manufacturing and logistics facilities.

Using OMRON's CX-Programmer software, ladder diagram programs were developed to interface with sensors, actuators, and control relays. Proximity sensors and limit switches were used to detect object size, and pneumatic actuators or diverter mechanisms were programmed to route objects to the correct sorting path based on detection signals.

The project spanned multiple practicum units, each covering different aspects of PLC programming including basic logic, timers, counters, and data comparison operations. The final project deliverable integrated all these elements into a comprehensive automated conveyor control system validated through simulation and testing on the laboratory PLC trainer kit.

Results

Key Outcomes

Developed a complete PLC ladder diagram program for automated size-based conveyor sorting using OMRON CX-Programmer.
Integrated sensor input logic, timer/counter operations, and actuator output control into a unified conveyor control system.
Completed multiple practicum units covering PLC fundamentals through advanced data comparison and sorting logic programming.
Produced comprehensive technical reports documenting the design, programming logic, testing procedures, and results for each unit.
