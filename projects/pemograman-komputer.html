Project Overview

About the Project

The Computer Programming course final project involved developing a functional desktop application for Power Factor Correction (PFC) calculations. Power factor correction is a critical process in electrical engineering to improve the efficiency of AC power systems by reducing reactive power and minimizing energy waste.

The application was built using Python with the CustomTkinter library for a modern graphical user interface. Users can input electrical parameters such as active power, apparent power, and current power factor to calculate the required capacitor bank values needed to achieve the target power factor. The UI design was also planned using Figma before implementation.

The application supports engineering professionals and students in performing power factor correction calculations quickly and accurately, eliminating manual formula derivation. The clean and intuitive GUI makes it accessible for both technical and non-technical users familiar with basic electrical concepts.
